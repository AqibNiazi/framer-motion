# Framer Motion Animations Demo 🚀

A **React 19** demo project showcasing different animations and transitions using **[Framer Motion](https://www.framer.com/motion/)**.
This project explores animation techniques with motion components, hooks, and advanced properties to bring UI interactions to life.

---

## ✨ Features

* Smooth animations powered by **Framer Motion**
* Usage of **motion components** for elements
* Examples of **animation hooks** like `useAnimation` and `useScroll`
* Variants for **complex animation sequences**
* Gestures: **drag, hover, and tap effects**
* Transition timing and easing customization

---

## 🛠️ Tech Stack

* ⚛️ **React 19**
* 🎞️ **Framer Motion**
* ⚡ **Vite** (for fast dev server and build)
* 🎨 **CSS Modules**

---

## 🚀 Getting Started

Clone the repository and run the app locally:

```bash
# Clone the repo
git clone https://github.com/AqibNiazi/framer-motion.git

# Navigate into the project
cd framer-motion

# Install dependencies
npm install

# Start the development server
npm run dev
```
